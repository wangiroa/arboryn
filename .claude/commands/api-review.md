# API Review Command

Review API endpoints for:
- RESTful design principles
- Error handling
- Input validation (DTOs)
- Authentication/authorization
- Response consistency
- Documentation completeness

Check:
1. HTTP methods match CRUD operations
2. Status codes are appropriate
3. DTOs validate all inputs
4. Guards protect routes
5. OpenAPI/Swagger docs exist
6. Rate limiting considered

Focus on $ARGUMENTS or all endpoints if not specified.
